# Mesure de couverture des sources

Exécuter `npm test` avec le runtime Node 24/npm fixé. Le pipeline lance une seule fois la suite Node native existante avec un seul worker, puis remappe ses véritables captures V8 avec la version exacte `c8@12.0.0`. Les échecs des tests natifs et les seuils natifs globaux de 60 % des lignes, branches et fonctions restent bloquants.

Ce frontend déclare `componentEnvironment: 'node'` dans `scripts/coverage-scope.cjs`. Ses véritables tests Node des vues serveur mesurent chaque fichier exécutable `src/**/*.ts` et `src/**/*.tsx`. c8 inclut les fichiers non importés avec `--all` ; chaque source inventoriée doit figurer dans le rapport. Le rapport corrigé doit atteindre 60 % des lignes, branches et fonctions globalement et 60 % des lignes pour chaque fichier, sans exception de source. Un score insuffisant fait échouer la commande ; aucun score provenant d’un autre environnement ne le remplace.

Les déclarations TypeScript sont également inventoriées et hachées. Un classificateur AST TypeScript strict reconnaît les fichiers composés uniquement d’alias de types, d’interfaces, d’imports de types ou d’exports de types effacés à l’exécution. Une erreur de parsing bloque la classification ; un import de valeur ou d’effet, une fonction, une classe, une enum, une valeur ou toute autre instruction empêche de classer une source exécutable comme un simple fichier de types. Les entrées sans code exécutable restent visibles avec LF/FNF/BRF à zéro, sans inventer d’instructions exécutées. Les déclarations `.d.ts` générées sont identifiées séparément dans la provenance. Les rapports c8 originaux restent identiques octet par octet dans `coverage/source-mapped/c8-raw/` avant que les reporters officiels Istanbul écrivent le rapport normalisé ; aucune source exécutable n’est exemptée des seuils.

`coverage/lcov.info` est le rapport principal corrigé transmis à la CI, identique octet par octet à `coverage/source-mapped/lcov.info`. Le LCOV natif, stdout, stderr, le résultat de l’exécution et les captures V8 brutes restent dans `coverage/native/`. Les empreintes des sources, des maps et des entrées ainsi que les résultats des seuils figurent dans `coverage/source-mapped/provenance.json`. Les rapports précédents sont déplacés dans `coverage/history/`. Le pilote archive le LCOV natif avant de le retirer du chemin principal. Une map absente, une source embarquée absente, une source modifiée ou un rapport invalide empêchent la publication principale. Un échec natif fait toujours échouer le pipeline même si le remappage réussit.

L’uploader CI partagé utilise explicitement le rapport principal avec la découverte automatique désactivée. Les preuves brutes restent dans le workspace local ou CI ; ce changement n’ajoute ni conservation persistante de ces artefacts en CI, ni transfert externe des données brutes. Les contrôles d’audit des paquets et de publication restent distincts et inchangés.
